# tools.mowne.co.in

Static showcase for [ML-Agent](https://github.com/mowne67/ML-Agent),
[pyinterpret](https://github.com/mowne67/pyinterpret),
[ERP-Assistant](https://github.com/mowne67/ERP-Assistant),
[rustpyxl](https://github.com/mowne67/rustpyxl),
[jsonpath-rx](https://github.com/mowne67/jsonpath-rx), and
[pydocx-fast](https://github.com/mowne67/pydocx-fast).

Served at <https://tools.mowne.co.in/>. This directory is the standalone site
root; it has no package dependencies or build step. See the
[repository README](../README.md) for development and Cloudflare Workers settings.

Imported from `mowne67/tools` at commit
`f43a1655ca22f801c7c2134e0eb18648a5b194ff`. Project descriptions and visual assets
come from that snapshot. Obsolete About navigation links were removed to match
the current profile site.

The rustpyxl, jsonpath-rx and pydocx-fast descriptions and examples were added
from their public repository READMEs on 10 October 2026 (see [SOURCES.md](../SOURCES.md)).
